# 桂东一中计算机社团总纲

> 规范 · 开放 · 协作 · 进取

桂东一中计算机社团是在学校指导下开展计算机技术学习、实践与交流的学生社团，围绕程序开发、硬件装配、人工智能、平面设计四个方向开展活动，致力于提升成员计算机素养、工程实践能力与技术创新意识。

---

## 一、总则

遵守国家法律法规、校纪校规和学校管理制度，坚持正确价值导向与开源共享，尊重成员差异，营造清朗、友善、包容的社团环境。

## 二、部门设置

| 部门 | 职责 |
| :--- | :--- |
| **程序开发与设计部门** | 程序开发、算法设计与软件项目实践；统筹并协调两个附属部门 |
| **硬件装配与搭配部门** | 硬件选型、装配、调试与维护；与软件部门联合协作 |
| **人工智能开发训练部门**（附属） | AI 智能体探讨、学习、训练与实践 |
| **计算机辅助平面设计部门**（附属） | 3D 建模、CAD 制图、简易动画与视觉素材设计 |

## 三、基本原则

1. **时效性**：关注前沿动态，及时学习新技术、新工具。
2. **团结协作**：成员互助，部门联合、分工配合。
3. **友善待人**：尊重他人设备与技术水平，文明交流。
4. **遵纪守法**：不制作、不传播违法及歧视性、攻击性内容。
5. **开源共享**：鼓励知识分享与集体提升，杜绝绝对化商业盈利思维。
6. **开放包容**：尊重兴趣差异，鼓励跨部门、跨年级平等交流。

## 四、组织架构

| 职务 | 职责 |
| :--- | :--- |
| **社长** | 统筹发展规划与各部门工作，召集会议，审定重要事项，对外沟通 |
| **副社长** | 协助日常工作，推进分管任务，社长缺席时代行职责 |
| **财务办** | 预算、收支记录、报销与财务公开，定期汇报 |
| **顾问** | 提供技术与管理咨询，参与评审、培训与验收 |
| **指导老师** | 指导审核活动、项目与制度，监督经费与安全事项 |
| **各部门部长** | 负责本部门项目统筹、学习安排、规范建设与任务分配 |

各部门可设副部长、项目负责人或小组长，由部长提名并按社团程序确定。

## 五、成员权利与义务

成员享有参加活动、使用公共资源、参与项目、提出建议和申请退出的权利；应遵守总纲与制度，爱护设备，按时完成任务，尊重他人劳动成果，不得以社团名义从事违规活动。

## 六、活动安排

技术分享会、项目实践、联合协作、竞赛展示、招新培训、期末总结。

活动须提前制定方案，明确负责人、时间、场地、物资与安全要求；重要活动报指导老师或学校审核。

## 七、会议与决策

定期召开例会，必要时召开临时会议。重大事项经社长、副社长、各部部长及指导老师讨论决定；经费、设备、安全事项按学校规定审批。会议形成简要记录。

## 八、资源与资产管理

公共设备、软件账号、代码仓库、设计素材与文档由相应部门登记管理。借用设备须登记并按期归还；代码文档鼓励开源，不得泄露隐私、学校敏感信息或违法内容。

## 九、考核与退出

按活动参与、任务完成、协作表现与项目成果进行阶段性评价。成员可申请退出；严重违规、恶意破坏设备或传播违法不良信息者，按学校规定和社团程序处理。

## 十、附则

本总纲经社团讨论、指导老师审核后生效，由社团负责人解释和修订。未尽事宜按学校制度执行。
